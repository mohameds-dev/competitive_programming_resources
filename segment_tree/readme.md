# Segment Tree

## Description

Generic segment tree implementation for range queries and point updates.

## File Structure

- **`code.hpp`**: Segment tree implementation
- **`main.cpp`**: Runs segment tree on `input.txt`
- **`tests.cpp`**: Unit tests using Catch2

## Setup

### Download Catch2

Tests use Catch2 for unit testing. Download the single-header version:

```bash
curl -L https://github.com/catchorg/Catch2/releases/download/v2.13.10/catch.hpp -o ../utils/catch2.hpp
```

Or download manually from [Catch2 releases](https://github.com/catchorg/Catch2/releases) and place it in `utils/catch2.hpp`.

## Complexity

- Time: Query/Update: O(log n), Build: O(n)
- Space: O(n)
